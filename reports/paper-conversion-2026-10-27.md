Paper conversion handoff — 2026-10-27

The paper image converts Word/PowerPoint/Excel, OpenDocument, RTF/text and HEIC/HEIF in its existing offline container. LibreOffice uses a disposable profile with macro security 3, NEVER_EXECUTE and NO_UPDATE. Calc gets explicit gridline and width/actual-size settings; PyMuPDF selects pages, applies orientation/fit/fill and makes slide handouts before Ghostscript measures and renders. Added fonts: Liberation, Carlito, Caladea and DejaVu. HEIC uses libheif and explicit HEVC decoder/encoder plugins.

Limits: input 20 MiB, 200 converted source pages, accepted intermediate PDF 100 MiB, PWG raster 512 MiB, 512 MiB individual file-write limit. Existing runtime stays offline/read-only, 2 GiB/2 CPUs/256 processes, 1 GiB tmp, ten minutes; runner now removes the container on timeout. Office gets 120 seconds, HEIC 45, measurement 120, rendering 300. First 20 output pages get PNG thumbnails at most 240px, 24 KiB base64 each and 512 KiB total, reducing dimensions for detailed pictures. These fit the site's 768 KiB report limit. A job may hit the raster/time limit before reaching 200 pages.

The hub asks the installed runner/image for formats, caches for 60 seconds and reports paperFormats in the heartbeat. Missing/old runner means no enhanced formats. Jobs with preview=true transport options and receive bounded preview/sourcePages/renderHash fields. The hub verifies the hash against the actual raster before asking the site to print. Older sites keep the original small reports and 30-page cap; no extended fields are sent. A converted format lacking the new preview protocol is refused. The existing physical-print receipt/outbox path is unchanged.

Members on the paired site can drop or choose a file, select only applicable options, see preparation progress and preview/count/price. Converted files always require Print or Cancel, including $0; the site binds approval to the raster hash. PDFs/pictures print as before unless paid-page confirmation applies. Migration 0269 makes preview/option deletion follow file deletion, adds staff visibility, and stops an older site dispatching queued enhanced jobs while ignoring their options.

Installation still uses the existing platform install-paper.py unchanged: its three copied files are still the entire paper build context. The host preflight `selftest` has no new dependency; Docker build runs `image-selftest`, which makes a tiny DOCX and HEIC, converts them, renders previews/PWG, and checks repeated raster hashes.
